# Mehmooni

**Learn Persian through real conversations.**

The idea for Mehmooni comes from a personal motivation: I want to learn Persian so I can better understand and participate in conversations with my girlfriend's Persian-speaking family.

Mehmooni is a web-based Persian (Farsi) learning application designed to help beginners understand and participate in everyday conversations.

Instead of focusing on isolated vocabulary, Mehmooni prioritizes listening comprehension, natural spoken expressions, and learning how to respond appropriately in context.

Mehmooni is still in its early stages. My goal is to create a simple and useful learning tool that helps me improve my Persian while giving me the opportunity to further develop my software engineering skills.
